The intersection of Java backend engineering, distributed systems, and applied AI is where I operate. Most of my production work is private by nature — enterprise systems, healthcare platforms, and AI pipelines built for real use cases.

What I'm working toward publicly:

- **AI-native healthcare systems** — combining Spring Boot, LangChain4j, and clinical data pipelines
- **Human performance analysis** — pose estimation with MediaPipe and OpenCV, backed by scalable Spring APIs
- **RAG & LLM orchestration** — production patterns for integrating LLMs into Java backends
